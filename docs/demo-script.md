# Demo script (about 4 minutes)

A recorded, captioned walkthrough is in [`demo/walkthrough.webm`](demo/walkthrough.webm),
generated by `apps/web/e2e/walkthrough.mjs --video out --slow`. Use this script to record a
narrated version over the deployed app (Loom, OBS, or the Windows Game Bar with `Win+Alt+R`).

| Time | Screen | Say |
|---|---|---|
| 0:00 | Login | "ACME's HR team manages pay for 10,000 people in nine countries in spreadsheets. This replaces that. I'll log in as the HR admin." |
| 0:20 | Dashboard | "First question an HR manager gets: how do we pay people? Headcount, payroll, median, and the spread, all in USD at dated planning rates so the numbers are reproducible." |
| 0:45 | Breakdown, Department; filter India | "Slice by country, department or level. Local-currency medians sit next to USD." |
| 1:05 | Heatmap | "Same level, different countries: where we pay more for the same job." |
| 1:20 | Employees, search, sort by salary | "The directory pages and sorts on the server. The URL keeps the view, so I can share it." |
| 1:45 | Profile | "Salary history is append-only. Every change has a date, a reason and who recorded it." |
| 2:00 | Record salary change: huge number, then 8% | "Validation comes from the API and shows on the field. A future date schedules a raise without changing today's numbers." |
| 2:30 | Add employee | "A new hire's starting salary becomes their first history entry. Picking a country sets the currency." |
| 2:50 | Import CSV with a bad row | "Imports are checked before anything is saved. One bad row, nothing imported, every problem with its row." |
| 3:15 | Payroll, run this month | "A payroll run freezes what each person is owed this month, per country, in local currency and USD. It records; it doesn't pay." |
| 3:40 | Log in as viewer | "A read-only HR viewer sees everything and can change nothing. The API enforces that too." |
| 3:55 | Repo README | "Requirements, decisions, AI usage and performance notes are all in the repo." |
